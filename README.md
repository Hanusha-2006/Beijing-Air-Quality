## Key Findings

- Developed a unified machine learning model to predict PM2.5
  concentrations across 12 Beijing monitoring stations.
- Compared the unified model against individual station models
  and a previous-hour persistence baseline.
- The unified model achieved an RMSE of 11.62 µg/m³,
  MAE of 6.68 µg/m³, and R² of 0.9806 on the aligned
  evaluation samples.
- Reduced RMSE by approximately 8.1% compared with individual
  station models and 40.6% compared with the previous-hour baseline.
- The unified model achieved the lowest station-level RMSE
  at all 12 stations in this experiment.
- Exploratory analysis revealed seasonal variations in PM2.5
  and relationships between pollutant and meteorological features.

## Conclusion

The results suggest that a unified model can effectively learn
shared air-quality patterns across multiple monitoring stations
and outperform separately trained station models on this dataset.
